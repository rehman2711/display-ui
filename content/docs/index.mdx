Display UI is a library of reusable React components that you can easily integrate into your web applications.

## ✨ Features

### 🎨 Fully Customizable

Display UI follows the design philosophy of shadcn/ui while leveraging Radix UI’s robust, declarative component architecture. This gives you components that are highly flexible and easily adaptable to your project’s design needs.

### 🚀 Developer-Friendly

With intuitive, declarative APIs, Display UI helps developers build interfaces faster, reduce boilerplate, and improve overall productivity. Built on Radix UI, these components are accessible out of the box.

### 🎭 Engaging Animations

Many components come with thoughtfully designed animations to enhance user experience, provide clear visual feedback, and make interactions feel smooth and natural.
